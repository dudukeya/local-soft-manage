# Local Soft Manage 使用操作手册

Local Soft Manage 用于把本地项目命令集中到一个窗口管理。每个项目只有一份启动配置，并拥有独立的 PowerShell 或 CMD 终端；切换右侧选项卡不会中断其他项目。

## 一、界面和使用流程

```text
┌──────────────────────────┬─────────────────────────────────────────┐
│ 左侧：项目与操作          │ 右侧：项目终端选项卡                     │
│                          │                                         │
│ 新建、搜索、选择项目       │ 每个项目一个 tab                         │
│ 启动项目 / CMD / PS       │ 可输入命令、查看输出、Ctrl+C              │
│ 停止、配置、删除           │ 切换 tab 保持各自 PTY 和滚动历史           │
└──────────────────────────┴─────────────────────────────────────────┘
```

推荐流程：

1. 点击左侧搜索框右侧的“+”按钮新建项目。
2. 填写项目名称、运行环境、访问路径、项目目录、分类、说明和执行命令。
3. 点击“保存项目”。保存后项目会出现在左侧并打开右侧终端选项卡。
4. 点击项目列表右侧的“⋯”菜单，选择“启动项目”执行保存的命令；也可以选择“打开 CMD”或“打开 PowerShell”只打开对应 Shell。
5. 在右侧终端直接输入命令，按 Enter 执行；使用 Ctrl+C 中断当前命令。
6. 管理多个项目时，点击右侧 tab 切换。未选中的项目终端仍在后台运行。
7. 工作结束打开项目的“⋯”菜单点击“停止项目”；修改配置后再从菜单启动。

左侧品牌栏右上角的收缩按钮可以折叠左栏。折叠后会保留一个窄图标栏，右侧运行窗口获得更多空间；再次点击展开按钮即可恢复项目列表。

## 二、新建项目字段

- **项目名称**：左侧列表和终端 tab 中显示的名称，必填且不能重复。
- **项目目录**：终端启动时的工作目录，必填。可以手动填写或点击“浏览”。
- **项目说明**：可选，用于记录用途、端口或启动注意事项。
- **运行环境**：选择项目默认使用的 PowerShell 或 CMD。
- **访问路径**：可选的 `http://` 或 `https://` 地址；填写后可从项目菜单直接用默认浏览器访问。
- **项目分类**：可选的单个分类名称，列表上方会自动生成分类标签；空值归入“未分类”。
- **执行命令**：必填，支持单行、多行以及 `.bat`、`.ps1`、`.exe` 文件。

项目目录不会被 Local Soft Manage 修改或删除，删除项目只删除应用中的配置。

## 三、分类、排序和浏览器访问

- 项目列表标题下方的分类标签可以筛选项目；搜索框会和分类条件叠加生效。
- 分类较多时，标签两侧会出现左右箭头；点击箭头可以横向浏览全部分类，不会挤压项目列表。
- 打开项目右侧“⋯”菜单，选择“上移项目”或“下移项目”调整顺序。排序会自动保存，搜索或分类筛选不会改变未显示项目的相对顺序。
- 填写访问路径后，菜单中的“浏览器访问”会调用系统默认浏览器打开；未填写访问路径时该项不可用。

右侧运行窗口顶部的主题按钮旁边是“设置”按钮。打开后可以维护项目分类字典：添加分类、删除分类或调整分类顺序，保存后会同步到新建/编辑项目的“项目分类”下拉框和左侧筛选标签。项目分类不预置默认值，删除字典项后，该分类不会再出现在筛选和表单选项中。

## 四、执行命令示例

### PowerShell 多行命令

```powershell
$env:PORT = "3000"
pnpm install
pnpm dev
```

### CMD 多行命令

```bat
set PORT=3000
call pnpm install
pnpm dev
```

多行内容会按原顺序写入项目终端。前台服务持续运行时，后续命令会等它退出后才执行，这是 Shell 的正常行为。

### 启动 `.bat`

项目目录为 `D:\web2api` 时，运行环境选 CMD，执行命令填写：

```bat
web2api.bat
```

在 PowerShell 中运行批处理文件时填写：

```powershell
.\web2api.bat
```

### 启动 `.ps1` 或 `.exe`

```powershell
.\start.ps1 -Port 8080
.\server.exe --port 8080
```

相对路径始终以项目目录为基准；路径包含空格时按 Shell 语法加引号。

## 五、终端选项卡

- 点击左侧项目会打开或激活该项目 tab；项目右侧的“⋯”菜单提供启动、Shell、停止、配置和删除操作。
- 每个 tab 对应独立的 PTY、Shell、工作目录、PID、输入和滚动缓冲。
- 切换 tab 只隐藏当前面板，不关闭进程。
- 终端选项卡较多时，选项卡栏两侧会显示左右箭头；点击箭头按一页宽度滚动，当前活动选项卡会自动滚入可视区域。
- “打开 CMD”和“打开 PowerShell”会为当前项目重建对应 Shell；旧 Shell 会被关闭。
- 关闭 tab 会结束该项目终端；再次选择项目会创建新会话。
- 终端窗口大小变化时会自动同步 PTY 行列数，复制、粘贴、方向键和 Ctrl+C 均可直接使用。
- 右上角的 `− / 当前字号 / +` 控件可调整终端字体，范围为 10–24px；每个项目终端独立记住当前字号。

## 六、Web2API 配置示例

假设批处理文件为 `D:\web2api\web2api.bat`：

1. 点击“新建项目”。
2. 项目名称填写 `web2api`。
3. 项目目录填写 `D:\web2api`。
4. 运行环境选择 **CMD**。
5. 执行命令填写 `web2api.bat`。
6. 保存后点击项目右侧“⋯”菜单中的“启动项目”，在右侧 CMD tab 查看服务输出。

如果脚本依赖 Python、Node.js 或其他程序，请先确认它们已安装并且可以在所选 Shell 的 PATH 中找到。

## 七、常见问题

### 保存失败

检查项目名称、项目目录和执行命令是否为空；检查名称是否与已有项目重复。新版本数据模型不再使用“动作列表”，表单中只配置一条执行命令。

本版本使用独立的 `soft-manage-v2.sqlite3` 数据文件，不读取旧版动作数据库；项目分类字典保存在其中的 `project_categories` 表，首次运行会自动创建新的项目存储。Windows 默认路径为 `%APPDATA%\com.ddk.softmanage\soft-manage-v2.sqlite3`；主题偏好仍保存在 WebView2 本地存储中。

### 启动后立即报错

先在终端检查工作目录、命令文件是否存在，以及 Python/Node/npm 等依赖是否在 PATH 中。`.bat` 通常选择 CMD，`.ps1` 通常选择 PowerShell。

### 看不到输出或终端空白

确认项目 tab 仍处于打开状态；切换 tab 不会停止进程。若 Shell 已退出，点击“重建终端”或重新选择项目后再启动。

### 端口被占用

先在对应项目 tab 中按 Ctrl+C 或点击“停止”，再检查占用端口的其他进程。
